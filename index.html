Importação de dados

Carga feita pela Rede Vilarejo. Os itens carregados aparecem no link do fornecedor, com os campos que faltam em destaque, para ele corrigir e completar.

Itens de um fornecedor

Escolha o fornecedor cadastrado e carregue a planilha dele. Se a planilha tiver itens de outros fornecedores, só entram os dele.

Base completa do ERP

Uma planilha com os itens de todos os fornecedores. Cada linha vai para o fornecedor pelo nome (coluna Fornecedor); os nomes não reconhecidos você escolhe na hora.

Envie sempre .xlsx (no CSV o Excel grava o NCM como 4E+07). O que não vier na planilha fica pendente para o fornecedor; célula vazia ou "-" não apaga o que já existe. Recarregar a mesma planilha atualiza os itens, sem duplicar.
